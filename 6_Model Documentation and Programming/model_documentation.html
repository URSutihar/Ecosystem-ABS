40.015 Simulation Modeling & Analysis

This page deck provides a comprehensive explanation of the Viridian-7 Ecosystem Agent Based Simulation (ABS) Model. The objective of this model is to simulate the predator-prey dynamic in an environment with competition and shocks, capturing the optimal strategy for survival.
The model accounts for multiple ecosystems with differnet prey and predator types, dynamic species behaviour, random shocks, reproduction and starvation.
